## JobLens 

JobLens is a web platform designed to help job seekers identify potential warning signs in job advertisements before applying.

The platform highlights suspicious details and provides verification suggestions rather than making the final decision about whether a job is genuine or fake.

## Features

Job advertisement analysis with warning signs and explanations

Text, URL, and image input options

Image upload and preview

Interactive analysis results and caution indicators

Job verification tips

Responsive design with animations and interactive elements

## Technologies Used

HTML5

CSS3

JavaScript

Netlify Functions (initial AI integration)

## Future Improvements

AI-powered analysis for more accurate and context-aware results

Text extraction from uploaded job advertisement images

Automatic content extraction from job posting links

Improved scam detection and verification features
